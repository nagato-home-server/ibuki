- eventnetdのUnix socketを`SOCK_CLOEXEC`／`accept4`で作成するようにした。strongSwan／VPP command backendのfork／execへAgent socketを漏らさず、常駐プロセスのdescriptor境界を閉じた。
- eventnetdの初回file入力と`--reload-config`経路に残っていた直接`fopen`を、`en_telemetry_open_jsonl`へ統一した。通常周期・reload周期のどちらでもsymlink／危険権限検査を通るようにし、入力境界の実装漏れを解消した。
- telemetry file loaderへ4MiBの総バイト上限を追加した。空行だけの巨大fileがrecord数制限を迂回する問題を防ぎ、file／socket／parallelで入力サイズの上限方針を統一した。
- CI workflowのYAMLをPython YAML parserで検証し、追加したLinux Sanitizer jobの構造を確認した。stale CMakeCache検出は旧`controller-c`を指す一時cacheで終了コード2になることを実測した。
- `docs/event-schemas.md`へtelemetry入力の4MiB上限とLinux file入力のsymlink／権限検査を追記した。JSONL契約だけでなく、eventnetdが受け入れるファイル境界も論文用仕様として明文化した。
- `vm-evaluate.sh all`をcase単位の失敗収集方式へ変更した。一つの依存不足や失敗で後続評価を飛ばさず、全caseのpass／partial／skip／failとログを一回のレポートへ残す。最終終了コードはfailの有無を維持する。
- 実装状況の再監査で、`docs/scenario-vs-production.md`と`実装方針.md`に残っていた「VPP Binary APIは未実装」「libvici本番transportは未実装」という古い表現を修正した。現在は低レベルVPP transport、生成message所有権境界、libviciの有限／無期限監視とeventnetd接合までを実装済みとし、VPPの版依存codec、rekey／DPD個別ポリシー、service再起動復旧を未完了として分離した。難しかった点は、全面未実装という表現を残すと到達点を過小評価し、逆に「本番対応済み」と書くと具体codecや運用復旧を過大評価するため、境界を機能単位で書き直したことである。
- 論文作成までと未踏期間中の作業を`docs/paper-to-mitou-roadmap.md`へ文章化した。論文前はYAML閾値をユーザ変更可能な土台、共通reconcile、IPsec／VPP runtime、Explain、再現評価の固定に集中し、論文後は実機・クラウドで閾値と通信影響を測定してからVPP Binary API、BGP、HA、必要に応じてFlow Preserveへ進む順序とした。閾値のYAML例とreload時の旧設定維持は`docs/yaml-routes.md`へ追記した。難しかった点は、未踏期間に機能を増やしすぎず、研究の中心である実測値に基づくPath Transitionの定量評価へ予算と実装時間を集中させる境界を決めたことである。
- Linux VMの`vm-build-cc.sh`で`O_NOFOLLOW`や`fdopen`が未宣言になった原因を修正した。CMakeビルドだけでなくCMakeなしビルドにも`_GNU_SOURCE`と`_POSIX_C_SOURCE=200809L`を渡し、POSIX安全ファイルAPIを同じ条件で利用できるようにした。VLAN sub-interface名はVPP interface名とVLAN IDの合成前に長さを検証し、固定長fieldを切り詰めない。Windows側ではC compilerがないため未検証であり、Linux VMで基準ビルドを再実行する。
- Linux基準ビルドで`eventnetd.c`がcontroller内部のopaqueな`state`と内部関数へ依存していた問題を修正した。`en_controller_find_path`と`en_controller_path_nodes_enabled`を公開APIとして追加し、daemonから内部構造体を直接参照しない形にした。CMakeなしビルドで先に露呈したが、CMakeビルドでも同じ公開境界を使うため、daemonとlibraryの結合を明確にできた。
- `_GNU_SOURCE`／`_POSIX_C_SOURCE`をビルドフラグとソースの両方で定義しても再定義警告が出ないよう条件付き定義にした。CMakeビルドとCMakeなしビルドの双方で同じPOSIX API宣言を利用する。
