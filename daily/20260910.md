# 20260910

## CI失敗の修正

- GitHub Actionsの`5a9a946`でLinux coreとLinux sanitizerのBuildが失敗していた。`CMakeLists.txt`はC拡張を無効にしているため、`apply_plan.c`で使用する`O_NOFOLLOW`、`fdopen`、`fchmod`などのPOSIX宣言が見えず、`O_NOFOLLOW undeclared`で停止していた。
- `src/apply_plan.c`自身で`_GNU_SOURCE`と`_POSIX_C_SOURCE 200809L`をヘッダより前に定義し、ビルド設定依存の宣言不足を修正した。
- WSLでLinux CMakeビルドを再実行し、全ターゲットのコンパイルまで成功した。CTestでは、relay終端の実際の測定対象`203.0.113.25`とCMake側の期待値`203.0.113.18`が不一致だったため、`CMakeLists.txt`の期待値を実際の終端トンネルに合わせて修正した。
- GitHub Actionsの警告は`actions/checkout@v4`がNode.js 20を使用していたことが原因だった。Node.js 24を使用する`actions/checkout@v5`へLinux core、Linux sanitizer、Windows coreの全ジョブを更新した。これは失敗原因ではなく、将来のNode.jsランタイム警告を解消するための更新である。
